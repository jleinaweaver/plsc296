Building a Causal Argument


“Causal inference refers to the process of drawing a conclusion that a specific treatment (i.e. intervention) was the ‘cause’ of the effect (or outcome) that was observed” (Frey 2018).


Remember, the aim of any scientific discipline is to generate new knowledge that explains why things happen in the world

  • We refer to this as explanatory or causal analysis

  • In short, we want to demonstrate that changes in our chosen predictors CAUSE a change in the outcome variable


SLIDE: And since we deal so frequently with observational data…

Making Controlled Comparisons

We develop identification strategies that identify the confounders in our observational relationships.

  • This is what the textbook refers to as a “controlled comparison” (p160)

  • The hope is that by controlling for all of the confounders we get to a place where the treatment and control groups are identical on average

1: We’ll start back at the original aggregate function output

  • This shows our data in a long form

  • e.g. Each combination of predictor and control gets a separate row

  • This form makes the line plot easy but a polished table hard


2: The pivot_wider function transforms these separate rows into columns

  • “names_from” asks what the new columns should be called and takes the new names directly from our control variable

  • “values_from” asks what numbers to put under each new column

  • SO, this function creates three columns from the drv variable and puts the value of city fuel efficiency under each one

  • Does this transformation make sense?


3 - 5: Now we just pipe everything into kable and kable_styling then tweak the output until we’re happy


SO, when you need R to make a polished cross-tab, we use the crosstable package

  • That counts the cells and converts to proportions


WHEN you already have the calculations done we use kable() to make the completed calculations look polished
