Why create an additive index of variables?

  1. May create a better estimate of a complex concept

  2. Allows a wider array of analysis tools

  3. May reduce random measurement error

So, imagine you have a handful of variables that are all nominal or ordinal and focus on the same basic underlying concept

  • We can use our tools from last class to combine them into a single, new interval variable

  • There are at least three possible benefits to creating a new interval variable


REVEAL: Create better estimates of a concept

  • Many concepts in political science are heavily contested and represent complex attitudes to the world (e.g. political ideology)

  • No single question may be able to completely represent what you are interested in measuring in a valid AND reliable way

  • In that case we can use multiple nominal or ordinal variables to measure all the related aspects of the concept

  • THEN we can combine them into a single interval measure of the concept


REVEAL: Allows a wider array of analysis tools

  • The second benefit relates to our univariate analysis tools

  • There’s simply way more tools available for analyzing an interval variable than a nominal varible

  • e.g. mean, median, percentiles VS a frequency table


REVEAL: May reduce random measurement error

  • In essence, each separate measure represents new information about the concept that were each measured with error

  • The hope is that these errors, if they are truly random, will start to cancel each other out when we combine them


Important caveat to this last one

  • Combining related measures measure helps with random error, NOT systematic error

  • If your measures are invalid, combining them won’t help

SLIDE: Now we can build the index

Building an Index (using nominal variables)

  • Convert the dummies, sum them, AND save as a new variable
anes$engagement_index <- 
  if_else(anes$polact.givecand == "1. Yes", 1, 0) +
  if_else(anes$polact.giveparty == "1. Yes", 1, 0) +
  if_else(anes$polact.giveoth == "1. Yes", 1, 0)

Let’s start by looking at the values in the first variable

  • As we noted before, each of the racial attitudes questions has five possible answers

  • Ideally, we’d like to preserve all of this variation in the measurement and translate it into the index

  • In other words, the new index should recognize that a respondent with a “Not too often” score is different from one with a “somewhat different” response


The good news is that our version of the ANES dataset has coded all of the ordinal variables as “ordered factors”

  • That means that each variable records the observations AND it knows how to order the possible responses to each question


REVEAL: We can see this with the levels() function

  • IF a variable is coded as a factor, this shows us the levels and their order

  • We’ll learn to convert ordinal variables into ordered factors in R later in the semester


REVEAL: SINCE the order is already built-in here, all we have to do is use the as.numeric function to translate the levels into their numeric order

  • This function converts the variable into numbers based on the levels of the variable

SLIDE: Once we have our variables as numbers, combining them is super easy!

Building an Index (using ordinal variables)

  • Convert the variable to a factor, convert the factor levels to numbers, sum them, AND save as a new variable
anes$racial_attitudes <- as.numeric(anes$oth.race.concern) +
  as.numeric(anes$oth.race.feel)
