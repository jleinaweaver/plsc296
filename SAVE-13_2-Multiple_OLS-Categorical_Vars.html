OK, how else are these two approaches the same?

  • Both offer null hypothesis testing in p-values (and the p-values are VERY similar)

  • Both offer null hypothesis testing in CIs

    • OLS needs an extra function, but the SE is right there for us


How are these approaches different?

  • BIG difference in terms of the null hypothesis testing!

  • Difference of means t-test is asks IF the groups are actually different from the null

    • Doesn’t tell you direction or magnitude

  • OLS significance test asks if your SPECIFIC, measured difference is a better fit to the data than the null

    • This estimates both direction and magnitude!

  • PLUS OLS gives us other useful ways to think about the fit (SEs, R2, Adjusted R2, shape and size of the residuals, etc)


SLIDE: In order to add our confounder in we need to change our formula for a line

Making Controlled Comparisons


Simple OLS Regression

\[ y = \alpha + \beta(x) + \epsilon \]

Multiple OLS Regression

\[ y = \alpha + \beta_1(x_1) + \beta_2(x_2) + ... + \beta_k(x_k) + \epsilon \]

A simple OLS regression is a bivariate test

  • One predictor used to model one outcome

  • We then interpret the beta coefficient (e.g. the slope of the line) as the effect on the outcome of increasing X by one


Multiple OLS regression is a multivariate test

  • We can now include as many predictor variables as we want in order to model an outcome

  • e.g. all the confounders we need to establish a causal argument!


Per the textbook, how is multiple regression like the controlled comparisons we have been doing so far?

  • In other words, how do we interpret the partial regression coefficients in the multiple regression?

  • (You CANNOT interpret ANY single coefficient without reference to the others!)

    • e.g. these are partial effects, not zero-order effects

  • To be clear, BOTH of these formulas describe a SINGLE line

  • In the multiple regression version the slope of the line is determined by ALL of these partial regression coefficients

  • That means the meaning of any one partial regression coefficient depends on holding all other predictor variables constant

  • This is the ceteris paribus condition


Questions on this intuition from the textbook?


Ok, textbook Exercise 5 asks why you shouldn’t select variables to maximize the adjusted R2.

  • Why is this a terrible idea?

  • (SLIDE)

Making Causal Arguments

\[ y = \alpha + \beta_1(x_1) + \beta_2(x_2) + ... + \beta_k(x_k) + \epsilon \]

Because we’re making causal arguments and not garbage can models

  • We’re not economists!


Maximizing adjusted R-square leads to overfitting your data

  • e.g. describing a line that so perfectly mirrors your sample it stops representing the population we are interested in!

  • Remember, the goal of inferential statistics is to learn about the population NOT perfectly describe the sample


Bottom line, if it isn’t your primary mechanism or a confounder then leave it out!

Any idea why our estimates from the multiple OLS no longer match the group means?

  • (Because they answer fundamentally different questions)

  1. Regression adjusts for all predictors

    • The group mean is the average ignoring all other factors
    • Regression produces partial effects where each value is adjusted for the others!

  2. If the group sizes are different, regression tries to treat each group more equally (up-weighting the small groups, down-weighting the large ones)

    • Our voter ID variable is 18 vs 32 so the regression will adjust to treat them as comparable

  3. Regression allows us to consider what if different types of voter ID impact turnout differently?

    • In that case, the means get adjusted
