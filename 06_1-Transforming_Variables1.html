# Create a new variable: Population in natural logs

# Univariate analyses

SLIDE: Let’s briefly unpack this

Original Scale

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
   1701   18840   35324   96130   75651 5105067

Log Scale

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  7.439   9.844  10.472  10.606  11.234  15.446 
exp(8)
[1] 2980.958
exp(9)
[1] 8103.084

The key here is that both of these distributions describe the same data

  • Taking the log has not changed the order of the counties at all

  • We are simply examining the differences between them on the log scale instead of the normal counting scale


The log scale expands differences at the low end and shrinks the differences at the high end

  • So this tall bar of small counties gets unpacked so we can see how much they differ from each other

  • And the huge outliers are still there but get pulled back towards the rest of the distribution


REVEAL: We use exponentiation to undo the log conversion

  • Here I’m showing you the population associated with a log value of 8 and a log value of 9

  • Moving from log 8 to log 9 means your county size increases from 3k people to 8k people

  • So, at the low end of the log scale small changes move you up the distirbution


SLIDE: At the other end of the scale

Original Scale

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
   1701   18840   35324   96130   75651 5105067

Log Scale

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  7.439   9.844  10.472  10.606  11.234  15.446 
exp(13)
[1] 442413.4
exp(14)
[1] 1202604

At the high end your population size must grow massively to move you further up the scale

  • Moving from log 13 to log 14 means your county size increases from 440k people to 1.2 million people!

  • Make sense?


The cool thing here is you can use a simple rule of thumb to interpret changes on the log scale

  • Each one unit move on the log scale is approximately a tripling of the underlying score

  • Technically a natural log relies on Euler’s constant of 2.72… but tripling is a useful approximation


So, in sum, we take the log if the distribution is right-skewed and this puts all of the values on the log scale

  • We read increases on the log scale as tripling the score

  • This will be something we do A LOT when we get to bivariate and multivariate analyses especially with regression

SLIDE: Problem 3

Problem

  • You want to focus on one level or region of a distribution

Solution

  • Create a dummy variable with ifelse()

PROBLEM: You are interested in investigating one part of a distribution only


For example here, let’s say we want to focus our analysis on front wheel drive cars only

  • SOLUTION: to address this we’ll create a dummy variable with ifelse()


SLIDE: Let’s start by talking about the if_else function

Using if_else to evaluate your data


# Create a vector of numbers
x <- c(1, 3, 5, 7, 9)


# Evaluate the numbers in the vector
x > 5
[1] FALSE FALSE FALSE  TRUE  TRUE


# Use if_else to evaluate AND re-label
if_else(x > 5, "Above median", "Below median")
[1] "Below median" "Below median" "Below median" "Above median" "Above median"

Step through the code


The if_else function is a super handy piece of code to learn

  • It basically has three elements

  • Element 1 is a test with a true or false answer

  • Element 2 is what you want to happen if the answer is true

  • Element 3 is what you want to happen if the answer is false


Essentially if_else gives us a way to evaluate the observations in a variable and to recode them as something else

  • Make sense?


SLIDE: Let’s apply this to our problem

# Focus on one level of a nominal or ordinal variable 
mpg$front_wheel <- if_else(mpg$drv == "f", "Front Wheel", "Other")

# Univariate analyses
table(mpg$front_wheel)

Front Wheel       Other 
        106         128 
barplot(table(mpg$front_wheel))

So, this code creates a new variable

  • The if_else test says that when the drive train value in the mpg dataset is “f” the observation should be marked “front wheel”

  • When it is false, it should be marked as other

First we use summary to find the quartiles, then we use cut to split the interval into bins

  • IMPORTANT 1: Go a bit below the minimum and above the maximum to capture those values

  • IMPORTANT 2: You must have one more “break” than you have groups!

    • The observations are being put into the bins between the values you have specified

    • SO, an engine with a 2 litre engine goes between 1.5 and 2.4
