# Fit the models
res1 <- lm(data = wdi, life_expectancy ~ measles_immune_pct)
res2 <- lm(data = wdi, life_expectancy ~ secondary_education_pct)
res3 <- lm(data = wdi, life_expectancy ~ fertility_rate)

# Output the table
modelsummary(models = list(res1, res2, res3), 
             fmt = 2, 
             stars = c('*' = .05), 
             gof_omit = "IC|Log|F",
             coef_map = 
               c("measles_immune_pct"= "Measles Immunizations (%)",
                 "secondary_education_pct" = "Secondary Education (%)",
                 "fertility_rate" = "Fertility Rate",
                 "(Intercept)" = "Constant"))

What explains the variation in maternal mortality ratios around the world?

  • Data: Spring2026-WDI_Data_Class_Selections-SHORT_LABELS.xlsx

Read slide


The World Health Organization (WHO) defines the maternal mortality ratio as “the number of maternal deaths during a given time period per 100,000 live births during the same time period.”

  • It essentially captures the risk of death from a maternal cause in a single pregnancy (proxied by a single live birth).


We’ll assume for the present purposes that this data is valid and reliable

  • Let’s begin with univariate analysis

  • Everybody make a histogram and get ready to describe the variation in our measure

  • (REVEAL and DISCUSS)


Where is the US on this scale?

  • (Around 20 which is 59th in the world)


What countries do this best?

  • (Belarus, Poland, UAE, Czechia, Israel, Norway)


What countries are at the bad end of this distribution?

  • (Nigeria, Central African Republic, Chad, South Sudan, Liberia)
